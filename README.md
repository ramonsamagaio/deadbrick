# DEADBRICK

DEADBRICK is a first-person zombie survival RPG built around a fully destructible micro-voxel world, systemic physics, procedural cities, scavenging, firearms, construction, and emergent simulation.

This repository is being bootstrapped from a clean-room systems analysis of the reference build supplied by the project owner. The goal is to reproduce the useful gameplay ideas and procedural principles while implementing original code, content, urban generation, zombie ecology, weapons, loot, and progression for DEADBRICK.

## Core pillars

- Destructible micro-voxel environment
- Layered procedural city generation
- Enterable multi-floor buildings
- Firearms and ballistic damage
- Zombie sensing, hordes, and population simulation
- Physical scavenging, salvage, crafting, and construction
- Persistent world damage and player-built defenses
- Systemic fire, structural failure, liquids/gas hooks
- RPG attributes, perks, skills, item quality, and progression

## Foundation status

The initial UE5 C++ foundation is being added under `Source/Deadbrick` with architecture notes in `Docs/`.
